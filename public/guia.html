Tu primer diagnóstico, paso a paso.

AI Act Local te ayuda a describir un uso de inteligencia artificial, descubrir qué cuestiones legales pueden afectarle y conservar las razones del resultado. No tienes que conocer los artículos ni preparar documentos antes de empezar.

La forma más fácil de empezar

Vuelve a la aplicación, pulsa «Nuevo diagnóstico», elige «Cuestionario» y añade un único uso concreto de IA. Responde lo que sepas y usa «No estoy seguro» para lo demás.

Elige cómo quieres empezar

Los tres modos producen el mismo tipo de expediente. Lo que cambia es cómo reúnes la información inicial.

RECOMENDADO PARA EMPEZAR

Cuestionario

Respondes preguntas cerradas directamente en la aplicación. No necesitas un asistente ni tocar la terminal.

  • Para usos que ya conoces.
  • Para aprender cómo funciona.
  • Para una primera orientación.

Inspección

Un agente o la CLI examina una web o repositorio y registra indicios. Las hipótesis deben confirmarse antes de convertirse en respuestas.

  • Para proyectos con código.
  • Para webs ya publicadas.
  • No descubre procesos internos.

Mixto

Combina indicios técnicos con tus respuestas. Es la vía más completa cuando conoces el negocio y puedes revisar el proyecto.

  • Para análisis de clientes.
  • Para dejar evidencias.
  • Para trabajar con un agente.
Importante: escribir una web o una carpeta al crear el diagnóstico solo guarda esa referencia. No inicia una inspección. La inspección se ejecuta desde tu asistente o desde la CLI.

Crea el expediente

En «Mis diagnósticos», pulsa Nuevo diagnóstico. Pon un nombre reconocible, la organización y la fecha. Para el primer intento, elige Cuestionario.

Ejemplo: “Revisión AI Act — Tienda Acme”.

Añade un uso concreto de IA

Un uso es una finalidad dentro de un proceso, no el nombre de una herramienta. Describe quién la utiliza, para qué y sobre quién produce efectos.

Bien: “El equipo de soporte usa un asistente para proponer respuestas a clientes”.
Demasiado amplio: “Usamos ChatGPT”.

Responde sobre ese uso

Las primeras preguntas sitúan a la organización y las siguientes se adaptan al caso. Abre «Ayuda para responder» cuando una opción no esté clara.

Si no puedes confirmarlo, selecciona No estoy seguro. El motor conserva la incertidumbre: no la interpreta como «No».

Añade otros usos por separado

Crea otro uso cuando cambien la finalidad, las personas afectadas o la forma de emplear la IA. Esto evita mezclar obligaciones diferentes.

Dos usos distintos: redactar publicaciones de marketing y filtrar currículos de candidatos.

Lee los resultados como un mapa

En «Resultados» verás clasificaciones posibles, roles, obligaciones, advertencias y preguntas pendientes. Abre cada hallazgo para conocer las reglas, respuestas y fuente utilizadas.

«Sin obligaciones especiales detectadas» no demuestra cumplimiento general: solo indica que el catálogo no activó una obligación específica con la información disponible.

Exporta o conserva una revisión

En «Informes y revisiones» puedes descargar PDF, DOCX, HTML, Markdown o JSON. Sellar revisión guarda el resultado y el catálogo exactos para reproducirlos después.

Sellar no es una firma electrónica ni una certificación legal. Para seguir editando, crea una nueva revisión.

Seis conceptos que conviene distinguir

Diagnóstico
El expediente de una organización o proyecto. Puede contener varios usos de IA.
Uso de IA
Una finalidad concreta dentro de un proceso y con unas personas afectadas determinadas.
Observación
Algo visto en una web, archivo o declaración. Por sí solo no es una respuesta confirmada.
Propuesta
Una posible respuesta sugerida a partir de evidencia. Solo influye después de que la aceptes.
Hallazgo
Una obligación o recomendación activada por el catálogo, con fuentes y dependencias.
Revisión sellada
Una copia inmutable y reproducible del expediente, resultado y catálogo de ese momento.

Preguntas frecuentes

¿Tengo que responderlo todo de una vez?

No. Cada respuesta se guarda al pulsar «Guardar y continuar». Puedes cerrar la aplicación y reanudar el expediente más tarde.

¿Qué hago si no conozco una respuesta?

Selecciona «No estoy seguro». La incertidumbre aparecerá en los resultados y podrás averiguar el dato después.

¿La herramienta decide si cumplo el AI Act?

No. Ofrece un diagnóstico preliminar trazable. El catálogo jurídico está en borrador y no sustituye la revisión profesional.

¿Inspeccionar una web descubre todos los usos de IA?

No. Una web solo muestra señales externas; no revela necesariamente procesos internos, contratos, datos o supervisión humana.

¿Puedo corregir una respuesta?

Sí, mientras el expediente sea editable. Abre «Revisar respuestas guardadas». Si ya lo sellaste, crea una nueva revisión.

¿Qué informe debería compartir?

PDF es cómodo para leer; DOCX permite editar; HTML se abre sin servidor; Markdown funciona bien con agentes; JSON conserva toda la estructura.
